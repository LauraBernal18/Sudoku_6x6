
# Sudoku 6x6 - Proyecto FPOE 2025-2
## Autores
ALVAREZ QUINTERO MARTIN STIVENSSON - 2372233
BERNAL LOZADA LAURA VALENTINA - 2437088


Este proyecto implementa un juego de Sudoku 6x6 con interfaz gráfica en JavaFX,
siguiendo el patrón de diseño MVC.

## Características
- Genera tableros válidos con única solución.
- Validación en tiempo real de las reglas del Sudoku.
- Botones de ayuda, verificar y nuevo juego.
- Interfaz intuitiva y colorida.

## Ejecución
Abrir el proyecto en **IntelliJ IDEA**   
y ejecutar la clase principal:  
`src/main/java/sudoku/Main.java`
